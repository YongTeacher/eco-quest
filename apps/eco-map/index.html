HOW TO IMPORT

CSV 등록 방법

  1. 반별 파일은 위에서 학급을 선택하고 `번호,이름` CSV를 올립니다.
  2. 전체 학년 파일은 학급 선택을 비워두고 `반,번호,이름` CSV를 올립니다.
  3. `모둠` 열이 있으면 함께 등록되고, 없으면 학생·모둠 탭에서 나중에 배정합니다.
  4. 모둠이 배정된 학생만 반·번호·이름·모둠을 입력해 로그인할 수 있습니다.
