HOW TO IMPORT

나이스 출석부 명렬표 등록 방법

  1. 나이스에서 교과목의 출석부 명렬표 XLSX·XLS·CSV를 내려받습니다.
  2. 학생·모둠 탭에서 1~9반 파일을 한꺼번에 선택하면 `반`, `번호`, `이름(성 명)` 열을 자동으로 찾아 합칩니다.
  3. 반 열이 없는 단일 파일은 학급을 선택하거나 파일명을 `1반.xlsx`처럼 지정합니다.
  4. 명단 등록 뒤 `1팀 - 1,2,4,6` 형식으로 팀을 일괄 배정합니다.
  5. 모둠이 배정된 학생만 반·번호·이름·모둠을 입력해 로그인할 수 있습니다.
