# 생태월드 — 우리 학교 생태 탐사 프로젝트

수업 코드로 참여하는 생태 조사·개인 생물도감 서비스입니다. 카카오 지도는 용인삼계고등학교를
중심으로 연결했습니다. Cloudflare D1/R2와 Pages Functions를 사용해 학생 로그인, 관찰 핀,
대표 사진 및 개인 도감을 저장하고 Google Sheets에 서버 간 동기화하도록 백엔드를 구성했습니다.

## 현재 구현 범위

- 수업 코드·반·번호·이름·모둠·PIN을 사용하는 학생 계정
- 별도 관리자 비밀번호를 사용하는 교사 화면
- 통합 및 1~9반 지도 탭, 생물 분류 필터, 카카오맵 군집 핀
- 카카오맵에서 발견 좌표를 먼저 지정하고 구체적인 장소명을 입력하는 위치 선택
- 공동 관찰 사진 1~3장 선택과 대표 사진 지정
- 사진·특징 분석 후 조사 후보 3개 제시 흐름(현재 기능 시험용 후보)
- 학생 조사 근거와 참고 자료 작성
- 개인 생물도감 기본 3개, 교사 승인 시 최대 5개 제한
- 전체 학급 현황과 Google Sheets 재동기화 관리자 기능
- 나이스 출석부 명렬표 CSV의 반·번호·이름 자동 인식(UTF-8/CP949)
- `1팀 - 1,2,4,6` 형식의 학급별 팀 일괄 배정과 학생별 수정
- 학교와 생태 공간을 담은 픽셀아트 로그인 배경
- 확대·다운로드·이미지 복사를 지원하는 휴대폰 로그인 QR

실제 AI 사진 동정, 도감 작성 전용 화면, 학생의 추가 도감 승인 요청과 예외 검토 화면은 다음 단계에서
연결합니다. 배포에 필요한 D1/R2 및 비밀 변수는 `docs/eco-quest-production.md`를 따릅니다.

모둠 계획서는 첫 수업에서 종이로 진행하므로 사이트 기능에 포함하지 않습니다.
