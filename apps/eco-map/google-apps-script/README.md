# ECO QUEST Google Sheets receiver

이 폴더는 교사가 소유한 Google 스프레드시트를 ECO QUEST 마스터 시트로 바꾸고,
Cloudflare 서버가 전송하는 학생·관찰·도감 데이터를 안전하게 반영하는 Apps Script입니다.

## 설치

1. `ECO QUEST 마스터 데이터` 스프레드시트를 엽니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. 기본 `Code.gs` 내용을 저장소의 `Code.gs` 내용으로 교체하고 저장합니다.
4. 함수 목록에서 `setupEcoQuest`를 선택해 한 번 실행하고 Google 권한을 승인합니다.
5. 스프레드시트로 돌아오면 `전체 현황`, `학생`, `공동 관찰`, `개인 생물도감`,
   `제출 현황`, `검토 필요` 탭이 생성됩니다.
6. Apps Script에서 `배포 → 새 배포 → 웹 앱`을 선택합니다.
7. 실행 계정은 `나`, 액세스 권한은 `모든 사용자`로 설정합니다. 웹 앱은 Cloudflare 서버만
   비밀키로 호출하며 학생 브라우저가 직접 호출하지 않습니다.
8. 배포된 `/exec` 주소를 복사합니다. 이 주소는 공개 저장소에 커밋하지 않습니다.
9. 스프레드시트의 `ECO QUEST → 동기화 비밀키 확인`에서 비밀키를 확인합니다.
   이 값 역시 공개 저장소나 학생에게 공유하지 않습니다.

웹 앱 주소와 비밀키는 Cloudflare Pages의 암호화된 환경 변수
`ECO_SHEETS_WEBHOOK_URL`, `ECO_SHEETS_WEBHOOK_SECRET`로만 등록합니다.

`학생` 시트의 `허용 도감 수`는 기본 `3`입니다. 추가 작성을 승인한 학생만 사이트의 교사 관리 화면에서
`5`로 바꾸며, 다음 동기화 때 시트에도 반영됩니다. 시트에서 이 값을 직접 수정하면 사이트 데이터에는
반영되지 않습니다.

## 보안 원칙

- 스프레드시트 ID, 웹 앱 URL, 동기화 비밀키를 GitHub에 저장하지 않습니다.
- 학생 브라우저는 Apps Script를 직접 호출하지 않습니다.
- 셀 수식 삽입을 막기 위해 외부 문자열이 `=`, `+`, `-`, `@`로 시작하면 일반 텍스트로 저장합니다.
- 동일 ID의 재전송은 행을 추가하지 않고 기존 행을 갱신합니다.
